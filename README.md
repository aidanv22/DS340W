This project is a semester long group research project that uses different machine learning techniques to predict injuries within sports.

There are three main papers referenced in this work, those being:
1. A novel approach for sports injury risk prediction: based on time-series image encoding and deep learning (Parent Paper) - https://pmc.ncbi.nlm.nih.gov/articles/PMC10773721/#_ad93_
2. Injury Risk Prediction and Prevention Algorithm for Athletes Based on Data Mining - https://pdfs.semanticscholar.org/ef34/ed6aae8c514623f9e095b863a5dcb4799ead.pdf
3. Predicting sports injuries with machine learning technology: Enhancing athletes’ life expectancy through biomechanical analysis - https://www.researchgate.net/publication/390044356_Predicting_sports_injuries_with_machine_learning_technology_Enhancing_athletes%27_life_expectancy_through_biomechanical_analysis


Our code for this research comes from the parent paper, and below are steps for one to replicate running this on their own machine:
1. Open a tab and go to https://colab.research.google.com
2. Open a new tab and go to https://github.com/aidanv22/DS340W
3. Click on the file titled "PARENT_PAPER_CODE_+_NOVELTY-2.ipynb" -> click the three dots button in the top right corner and click download
4. Go back to the homepage by clicking the blue "DS340W" button
5. Click on the "Parent Paper" folder -> then click on the "DATASETS" folder -> click on the "train-1.csv" file -> click the three dots button in the top right corner and click download
6. Go back to the Google Collab tab we opened in the first step -> click on the "upload" tab on the left of the pop-up -> click the blue "browse" button -> click on the "PARENT_PAPER_CODE_+_NOVELTY-2.ipynb" file
7. Once that file is loaded, click on the "folder" icon on the left of the screen -> click the "upload" button within the files tab
8. Click on the "train-1.csv" file you downloaded earlier -> hit "OK" to the pop-up warning
9. You can now run each cell block one after another, and should be able to replicate the parent paper + our novelty code! Enjoy :)
